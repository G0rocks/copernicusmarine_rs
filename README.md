# Copernicus Marine Rust
This project is made to enable the use of the copernicus marine toolbox through rust


I did ask Blu (the coperniucs machine learning assistant) for permission to make this beforehand and Blu said it was ok.

## How to use
You must start by installing the [copernicus marine toolbox](https://github.com/mercator-ocean/copernicus-marine-toolbox) which you can do with pip
```
pip install copernicusmarine
```
Make sure it is set up correctly by running 
```
copernicusmarine --version
```

Before using the crate you must run
```
copernicusmarine login
```
to set up your credentials. It should be enough to run that once.


Remember to cite copernicusmarine in your works.
[https://help.marine.copernicus.eu/en/articles/4444611-how-to-cite-copernicus-marine-products-and-services](https://help.marine.copernicus.eu/en/articles/4444611-how-to-cite-copernicus-marine-products-and-services)
